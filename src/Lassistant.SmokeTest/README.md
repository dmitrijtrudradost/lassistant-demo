# Smoke-проверки Lassistant Demo

Из корня репозитория на Windows с .NET 8 SDK:

```powershell
dotnet run --project src/Lassistant.SmokeTest/Lassistant.SmokeTest.csproj -c Release
```

Обычный запуск создаёт временный DOCX с вымышленными данными и выполняет четыре проверки:
- удаление точных дублей найденных сущностей;
- извлечение текста, координаты фрагментов и разделение сторон таблицы;
- замена номера договора на поле шаблона, включая текст, разбитый на несколько Word runs;
- сохранение результатов до и после ручного исправления.

Также проверяется неизменность исходного DOCX. Временный договор и ожидаемый текст удаляются после запуска.
Код возврата 0 и сообщение `ALL 4 SMOKE CHECKS PASSED` означают успех; ненулевой код означает ошибку.

Excel и OCR в этот набор не входят. Python и веса модели для обычного запуска не нужны.

## Дополнительные проверки модели

Существующие режимы `--contract-ner-check <input.docx>` и `--contract-template-check <input.docx>` сохранены.
Они требуют отдельной подготовки Python-окружения, весов модели и конфигурации рядом с исполняемым файлом тестов.
Их успешное прохождение не подразумевается результатом обычного запуска.
