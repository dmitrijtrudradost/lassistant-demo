# Lassistant — помощник юриста

> Локальная программа собирает реквизиты из договора, убирает персональные данные и заполняет шаблон Word. Документ не уходит в облако.

**Версия 1.6.6.2.** Карточки в `config/executors.json` вымышленные («Северная стража», «Городской пост», «Речная охрана», проект «Северный квартал»). Это публичный снимок для ознакомления.

## Проблема

Юрист переносит стороны, объект, цену и сроки из договора в новый документ вручную. Персональные данные заказчика при этом легко уехать во внешний сервис. В таблицах реквизитов модель путает колонки «Исполнитель» и «Заказчик», особенно когда заказчиков несколько и заголовок стоит не в первой строке.

## Решение

Настольное приложение для Windows читает договор на этом компьютере. Локальная NER-модель находит ролевые поля (не просто «ФИО», а «ФИО исполнителя» или «сумма договора»). Найденный фрагмент подставляется в шаблон `{{роль}}` или заменяется при анонимизации. Сторона в таблице берётся из заголовка колонки и из строк вроде «Заказчики» / «ИСПОЛНИТЕЛЬ:», а не только из догадки модели.

## Что внутри

- Технологии: .NET 8, WPF, Python 3.11/3.12, `cointegrated/rubert-tiny2`, Git LFS для весов модели
- Модель: NER v1.1.1, каталог `models/contract-ner/ner_model_1.1`, 76 ролей. Откат: `ner_model_1.0`
- Архитектура: интерфейс → извлечение текста договора → инференс `scripts/contract_ner/` → подстановка в DOCX. Слои: [ARCHITECTURE.md](ARCHITECTURE.md)
- Поставка: Windows 10 (1809+) / Windows 11, x64. Сборка `scripts\publish.bat` даёт `publish\win-x64\Lassistant.exe`. Сеть для обработки договора не нужна

## Как запустить

```bat
git clone https://github.com/dmitrijtrudradost/lassistant-demo.git
cd lassistant-demo
scripts\publish.bat
```

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Для распознавания реквизитов ещё Python 3.11 или 3.12 и окружение из [установки](docs/руководства/INSTALL_v1.6.6.2.md). Путь к Python в `config/contract-ner.json` оставьте пустым: программа ищет его сама. Запуск: `publish\win-x64\Lassistant.exe`.

## Результат

На синтетических договорах, без смены весов модели:

| Проверка | Было | Стало |
| --- | --- | --- |
| 100 договоров, сторона в таблице реквизитов | 544 ошибки из 3 909 | 20 из 3 909 |
| 20 договоров с пятью заказчиками, нестандартные таблицы | 1 179 ошибок из 2 156 | 60 из 2 156 |

До версии модели 1.2 вне таблиц с заголовками сторон ещё путаются ОГРН, КПП, ОКПО и ОКВЭД. Если вторая таблица реквизитов без заголовков, в списке находок бывают пары `заказчик_…` / `исполнитель_…` с одним и тем же текстом.
