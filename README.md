# Lassistant — помощник юриста

> Локальный помощник юриста для анонимизации, создания шаблонов и автоматического заполнения документов.

## Проблема

Юристу необходимо соблюдать требования Федерального закона № 152-ФЗ «О персональных данных» при работе с договорами и другими юридическими документами. Для дальнейшей работы с внешним ИИ требуется локально обезличить документ с возможностью последующего восстановления исходных сведений. Создание шаблонов из готовых договоров и заполнение многостраничных документов реквизитами заказчиков требуют повторяющейся ручной работы.

[Наименование закона в правовой базе Минюста России](https://minjust.gov.ru/ru/appeals/legal/).

## Решение

Lassistant локально распознаёт персональные данные и реквизиты с учётом их роли в договоре. Приложение помогает обезличить документ для работы с ИИ и затем восстановить исходные сведения. Второй инструмент позволяет создавать шаблоны из готовых документов и автоматически заполнять их данными из базы карточек заказчиков.

### Анонимизация и восстановление данных

Lassistant помогает находить персональные данные и реквизиты в документе, заменять их обозначениями (плейсхолдерами) и сохранять соответствие между обозначениями и исходными сведениями.

Подготовленный документ можно использовать для дальнейшего анализа и редактирования с помощью ИИ. После обработки приложение позволяет восстановить исходные сведения по сохранённому соответствию.

Анонимизация и обратная подстановка выполняются на компьютере пользователя.

### Создание шаблонов и заполнение документов

Из обычного договора или другого юридического документа можно подготовить новый шаблон — определить изменяемые сведения и заменить их полями для последующего заполнения.

Реквизиты заказчика вносятся в карточку. Из сохранённых карточек формируется база реквизитов заказчиков. При создании документа приложение подставляет данные из выбранной карточки во все предусмотренные поля шаблона по всему тексту.

Карточки и шаблоны можно использовать повторно при подготовке следующих документов.

## Что внутри

- Технологии: .NET 8, WPF, Python 3.11/3.12, `cointegrated/rubert-tiny2`, Git LFS для весов модели
- Модель: NER v1.1.1, 80 типов сущностей в файле меток; каталог `models/contract-ner/ner_model_1.1`. Модель для отката — `ner_model_1.0`
- Архитектура: интерфейс → извлечение текста договора → инференс `scripts/contract_ner/` → подстановка в DOCX. Слои: [ARCHITECTURE.md](ARCHITECTURE.md)
- Поставка: Windows 10 (1809+) / Windows 11, x64. Сборка `scripts\publish.bat` даёт `publish\win-x64\Lassistant.exe`. Сеть для обработки договора не нужна

## Как запустить

Понадобятся Windows 10 версии 1809 или новее либо Windows 11, разрядность x64, Git с Git LFS, .NET 8 SDK и Python 3.11 или 3.12, доступный через команду `python`.

Для получения зависимостей и весов модели нужен интернет. Обработка документов выполняется локально.

### 1. Получить проект и веса модели

Команды для PowerShell:

```powershell
git lfs install
git clone https://github.com/dmitrijtrudradost/lassistant-demo.git
cd lassistant-demo
git lfs pull
```

### 2. Собрать приложение

Перед сборкой закройте запущенную копию Lassistant.

```powershell
.\scripts\publish.bat
```

Обычный каталог результата — `publish\win-x64`. Если скрипт укажет другой каталог, используйте его в следующих командах.

### 3. Подготовить окружение распознавания

Из корня репозитория:

```powershell
python -m venv publish\win-x64\python-venv-contract-ner
.\publish\win-x64\python-venv-contract-ner\Scripts\python.exe -m pip install -r scripts\contract_ner\requirements-infer.txt
```

Окружение размещается рядом с приложением, где Lassistant ищет его автоматически. В `config\contract-ner.json` внутри каталога сборки поле `python_path` можно оставить пустым.

### 4. Запустить приложение

```powershell
.\publish\win-x64\Lassistant.exe
```

Для проверки используйте документ с вымышленными данными. Проверьте распознавание реквизитов, анонимизацию с восстановлением сведений, создание шаблона и заполнение из карточки заказчика.

Подробная установка и разбор возможных проблем приведены в [инструкции проекта](docs/руководства/INSTALL_v1.6.6.2.md).

## Результат

Рабочая версия Lassistant используется у заказчика. В этом репозитории представлена демонстрационная версия для ознакомления.

Приложение помогает подготовить документ к работе с ИИ и затем восстановить исходные сведения, создавать шаблоны из готовых документов и сокращать повторный ручной перенос реквизитов. Юрист проверяет найденные данные и готовый документ.

В описаниях версий зафиксировано уменьшение числа ошибок определения стороны в таблицах реквизитов на синтетических договорах, без изменения весов модели.

| Набор проверки | Ошибки до изменений | Ошибки после изменений |
|---|---|---|
| 100 договоров | 544 из 3 909 | 20 из 3 909 |
| 20 договоров с пятью заказчиками и нестандартными таблицами | 1 179 из 2 156 | 60 из 2 156 |

Источники показателей — [описание версии 1.6.6](docs/realese_history/RELEASE_v1.6.6.md) и [описание версии 1.6.6.2](docs/realese_history/RELEASE_v1.6.6.2.md).

**Известные ограничения.** Вне таблиц с заголовками сторон возможны ошибки определения ОГРН, КПП, ОКПО и ОКВЭД. Если таблица реквизитов не содержит заголовков сторон, в списке находок могут появляться пары полей заказчика и исполнителя с одинаковым текстом.

Размещайте проект в коротком каталоге, например `C:\Projects\lassistant-demo`: слишком длинный путь может вызвать ошибку установки Python-зависимостей.
