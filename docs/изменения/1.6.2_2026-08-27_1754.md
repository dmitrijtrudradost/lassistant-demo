## Конвертация в HTML

- Новый конвертер `scripts/md_to_html.py`: заголовки, таблицы, вложенные списки, чек-листы `- [ ]`, блоки кода, ссылки, `**жирный**` рядом с `` `кодом` ``
- Стиль и поля страницы как в словаре полей — HTML пригоден для печати в PDF из браузера
- `docs/руководства/INSTALL_v1.6.2.html` — инструкция по установке
- `docs/руководства/rukovodstvo_polzovatelya.html` — руководство пользователя
- В `INSTALL_v1.6.2.md` убраны пометки «PDF не обновлён», добавлена ссылка на HTML-версию
- `Руководство_пользователя.pdf` пересобран из нового HTML

Пересборка: `python scripts/md_to_html.py docs/руководства/<файл>.md`

## Окно «О программе»

- Новое окно `src/Lassistant.App/AboutWindow.xaml(.cs)` вместо `MessageBox`
- Кнопки **Да / Нет** убраны, осталась одна — **Закрыть** (Esc, Enter)
- Кликабельные ссылки: руководство пользователя, словарь полей шаблона, инструкция по установке, папка с документацией; полный путь в подсказке
- Приоритет форматов для руководства: `.html` → `.pdf` → `.md`; инструкция ищется по маске `INSTALL_*.html` (переименование при смене версии не требуется)
- Отсутствующий файл — серая строка «файл не найден» вместо ссылки
- Показываются версия программы и версия модуля NER
- `MainWindow.About_Click` сведён к открытию окна, лишние `using` убраны
