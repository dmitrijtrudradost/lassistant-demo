## Изменения

1. **ИП + пост охраны** в форме «Создать документ»: шаблон `договор_ип_пост_охраны.docx` (копия с `договор_юрлицо_пост_охраны.docx`).
2. **Юрлицо + пост охраны:** одна запись каталога на `договор_юрлицо_пост_охраны.docx`; удалены старые `demo_*` / северный квартал.
3. **Исполнители:** `severnaya_strazha` / `gorodskoy_post` → `severnaya_strazha` / `gorodskoy_post`.
4. **`outputNamePattern`** во всех строках каталога приведён к виду `типдокумента_{заказчик_кратко}_услуга_{датавремя}.docx` (фактическое имя файла при сохранении — `BuildOutputFileName` из 1.5.4.4).

Архив: `release/Lassistant_v1.5.4.5_win-x64.zip`.
