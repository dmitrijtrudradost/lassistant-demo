# Lassistant 1.6.6

Дата: 2026-10-21  
Базовая линия: **1.6.5.2**  
Модуль NER: **1.1.1** (без смены весов)

## Summary

- В таблицах реквизитов Исполнитель и Заказчик теперь различаются по заголовку колонки, а не по догадке модели. На 100 тестовых договорах ошибок стороны в таблицах стало 20 из 3 909 вместо 544.
- Исправлены метки не той стороны в пяти шаблонах (`templates\`).
- Новый шаблон `договор_юрлицо_пост_охраны_множ`: до пяти заказчиков, у каждого свои метки `{{заказчик_…_1}}` … `_5`.
- Удалены неиспользуемые Excel-шаблоны в `templates\`.

## Совместимость

Настройки `user/` и модель NER не меняются. Обновление с 1.6.5.2 — замена файлов программы, папку `user` не затирать. Метки в шаблонах заказчика не изменились, кроме перечисленных исправлений; если вы правили свои копии шаблонов, они остаются прежними.

## Проверка

1. Настройки → Общие: версия **1.6.6**.
2. «Шаблоны» → договор с таблицей «ИСПОЛНИТЕЛЬ | ЗАКАЗЧИК»: все реквизиты левой колонки получают роли `исполнитель_…`, правой — `заказчик_…`. Для договора, где Заказчик стоит в первой колонке, наоборот.
3. «Создать документ» → `договор_юрлицо_пост_охраны_множ`: в форме отдельные поля для каждого из пяти заказчиков.
