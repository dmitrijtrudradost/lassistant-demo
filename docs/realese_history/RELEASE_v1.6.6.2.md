# Lassistant 1.6.6.2

Дата: 2026-10-21  
Базовая линия: **1.6.6**  
Модуль NER: **1.1.1** (без смены весов)

## Summary

- Договоры с несколькими заказчиками: строка «Заказчики» над реквизитами заказчиков и «ИСПОЛНИТЕЛЬ:» ниже задают сторону ячеек. На 20 тестовых договорах с пятью заказчиками ошибок стороны в таблицах стало 60 из 2 156 вместо 1 179.
- Вложенная таблица реквизитов без своего заголовка берёт сторону ячейки, в которой лежит.
- Преамбула: сторона каждой части — по словам «именуемое в дальнейшем «…»», Заказчик может стоять первым. Сторона из преамбулы больше не переносится на весь договор.
- Строка подписей под «Исполнитель   Заказчик»: левая подпись — Исполнитель, правая — Заказчик, ФИО не дробится.

## Совместимость

Настройки `user/`, модель NER и шаблоны не меняются. Обновление с 1.6.6 — замена файлов программы, папку `user` не затирать. Для обычных договоров с таблицей «ИСПОЛНИТЕЛЬ | ЗАКАЗЧИК» результат тот же, что в 1.6.6.

## Известные проблемы

- Если в договоре есть вторая таблица реквизитов без заголовков сторон, в списке находок появляются пары `заказчик_…` / `исполнитель_…` с одинаковым текстом. Снимите галочку у лишней.

## Проверка

1. «О программе»: версия **1.6.6.2**.
2. «Анонимизация» → договор с несколькими заказчиками (строка «Заказчики»): реквизиты заказчиков — `заказчик_…`, реквизиты под «ИСПОЛНИТЕЛЬ:» — `исполнитель_…`.
3. Договор, где Заказчик назван в преамбуле первым: стороны в преамбуле верные.
