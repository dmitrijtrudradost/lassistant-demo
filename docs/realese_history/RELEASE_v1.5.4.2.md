## Назначение

Фиксация стабильного состояния **до** эксперимента с пайплайном NER (стороны/границы).

Точки полного отката:

| Что | Архив / папка |
|-----|----------------|
| Сборка (exe) | `release/Lassistant_v1.5.4.2_win-x64.zip` |
| Исходники проекта | `release/Lassistant_v1.5.4.2_src.zip` |

Следующая экспериментальная сборка (после вашего подтверждения): **1.5.4.3**.

## Относительно 1.5.4

Накоплено после релиза 1.5.4 (10.08.2026), без отдельного zip до этой фиксации:

1. Шаблон договора юрлицо / ГБР (`templates/договор_юрлицо_гбр.docx`), ключи в форме и `placeholder-roles.json`.
2. Справочник исполнителей дополнен полями шаблона ГБР.
3. Форма «Создать документ»: гарантированный блок полей исполнителя; подгруппы внутри категорий (Название, ФИО, Реквизиты, Банк, Лицензия, Контакты / Договор, Объект, Цена).
4. Profile-fallback без заголовка «Данные юрлица» — те же 4 категории.
5. Убраны с формы: `исполнитель_фио_кратко`, `исполнитель_город_банка`, `исполнитель_директор_фио`, `исполнитель_регион_лицензии`.

Contract NER / модель — без изменений относительно 1.5.4 (Этап A сохранён).

## Откат

**Exe / publish:** распакуйте `release/Lassistant_v1.5.4.2_win-x64.zip` поверх `publish\win-x64` или запускайте из `release\Lassistant_v1.5.4.2_win-x64\`.
