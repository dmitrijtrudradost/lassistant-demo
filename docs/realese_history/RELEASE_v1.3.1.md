| Параметр | Значение |
|----------|----------|
| Версия | **1.3.1** |
| Сборка | `1.3.1.0` |
| Дата | 08.07.2026 |
| Платформа | Windows 10 (1809+) / 11, x64 |
| Runtime | .NET 8 (self-contained) |

## Ключевые изменения

Полный пайплайн подготовки шаблона договора с помощью внешней LLM:

1. **Анонимизировать для LLM** — docx с цветными выделениями → `_for_llm.txt` + `_for_llm.docx`
2. **Анализ LLM** — отправка анонимизированного текста в модель, автозаполнение ключей плейсхолдеров
3. **Сохранить шаблон** — замена выделений на `{{ключ}}`

## Состав поставки

```
Lassistant_v1.3.1_win-x64/
├── Lassistant.exe
├── config/          — llm-settings.json, правила анонимизации, словари полей
├── templates/       — шаблоны документов
├── scripts/         — ner_helper.py (опционально)
├── docs/            — документация и CHANGELOG

```

## Критерии приёмки

- На контрольном договоре охраны (ИП) без интернета: сущности видны в UI, шаблон сохраняется с `{{заказчик_фио}}`, `{{дата_договора}}` и др.
- Без установленной модели ПЮ не падает: сообщение «модуль NER не установлен»
- ПДн на этапе разбора **не** отправляются на внешний API
- Документация: [LOCAL_CONTRACT_NER.md](LOCAL_CONTRACT_NER.md)

## Настройка LLM

Отредактируйте `config/llm-settings.json` только если используете **запасной** режим LLM.
Основной путь создания шаблона — локальный NER (см. [LOCAL_CONTRACT_NER.md](LOCAL_CONTRACT_NER.md)).
