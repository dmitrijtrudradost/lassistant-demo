## Ключевые изменения

Относительно 1.5.3:

1. **«Создать документ» — форма по `{{плейсхолдерам}}`**  
   Поля строятся из выбранного `.docx` (группы: Исполнитель / Заказчик / Договор и объект).

2. **Пилот: Договор ИП — пожарная сигнализация**  
   Шаблон `templates/Договор_ИП_пожарная_сигнализация.docx` (~39 ключей), в т.ч.  
   `исполнитель_огрн`, `исполнитель_почтовый_адрес`, `заказчик_наименование_кратко`.

3. **Справочник исполнителей**  
   До 3 карточек в `config/executors.json`, ComboBox на вкладке, автозаполнение `исполнитель_*`.  
   Заполнена карточка ООО «Речная охрана».

4. **Карточка заказчика (локально)**  
   Папка `data/заказчики/{тип}_{название}.md`.  
   Кнопка «Обновить карточку заказчика»; импорт `.md` через зону «Перетащите сюда файлы».  
   Сохраняются `заказчик_*`, договор и объект (`дата_договора`, `номер_договора`, `объект_*`, `цена_*`).  
   Merge с подтверждением при конфликте значений.

5. **Миграция старых шаблонов**  
   `[inn]` → `{{inn}}` (бэкап: `templates/_backup_brackets_pre_1.5.4/`).

## Установка Python для NER

```bat
cd scripts\contract_ner
python -m venv ..\..\python-venv-contract-ner
..\..\python-venv-contract-ner\Scripts\pip install -r requirements-infer.txt
```

## Критерии приёмки

- В «О программе» — версия **1.5.4**
- Договор → ИП → пожарная сигнализация: форма с полями из шаблона, выбор исполнителя заполняет `исполнитель_*`
- «Обновить карточку заказчика» пишет `.md` в `data/заказчики/`
- Перетаскивание `.md` карточки заполняет форму (включая договор/объект)
- «Создать документ» сохраняет заполненный `.docx`
