## Назначение

Сборка включает:

1. **Contract NER (с 1.5.4.3)** — улучшения пайплайна распознавания (стороны и границы) **без** переобучения модели; для тестирования на реальных договорах.
2. **Создать документ (новое в 1.5.4.4)** — стандарт имени файла и красная заливка незаполненных плейсхолдеров.

Откат стабильной базы до NER-эксперимента: `release/Lassistant_v1.5.4.2_win-x64.zip` + `release/Lassistant_v1.5.4.2_src.zip`.  
Промежуточный NER-only: `release/Lassistant_v1.5.4.3_win-x64.zip`.

## Изменения Contract NER (из 1.5.4.3, в этой сборке)

Для тестирования распознавания текста / сущностей в договорах:

1. **Преамбула:** абзацы с обеими сторонами режутся по якорю `с одной стороны, и …` на два NER-чанка с разными `party_hint` (исполнитель / заказчик). Номер договора, предмет, цена не затрагиваются.
2. **Таблица реквизитов:** маркеры `ИСПОЛНИТЕЛЬ:` / `ЗАКАЗЧИК:` (с двоеточием) распознаются; sticky стороны из body не протекает в ячейки.
3. **Границы:** `expand_address` / `expand_textual` не выходят за конец NER-чанка (ячейка / кусок преамбулы). Sentence-NER не включался.

Модель / `labels.json` не менялись. Подробнее: `docs/realese_history/RELEASE_v1.5.4.3.md`.

## Изменения «Создать документ» (новое в 1.5.4.4)

1. **Имя файла:** `типдокумента_заказчик_кратко_типуслуги_yyyyMMdd_HHmmss.docx`  
   Пример: `договор_ООО_Ромашка_гбр_20260813_171530.docx`.  
   Краткое имя заказчика: `заказчик_наименование_кратко` → `заказчик_фио_кратко` → полное имя; иначе `без_заказчика`.  
   Услуга: `монтаж` / `пс` / `гбр` / `пост_охраны`.

2. **Пустые плейсхолдеры:** в документе остаётся текст `{{ключ}}` с заливкой фона `#FF0000`; цвет шрифта не меняется.
