# Lassistant 1.6.4

Дата: 2026-09-23  
Базовая линия: **1.6.3**  
Модуль NER: **1.1.1** (без смены весов)

## Summary

- Со вкладки «Шаблоны» убран запасной облачный разбор договоров (LLM).
- В приложении больше нет сетевого вызова к OpenAI-совместимому API или Anthropic и конфига `llm-settings.json`.
- Кнопка поиска на «Шаблонах» и «Анонимизации» называется **«Найти сведения»**. Порог в интерфейсе называется **уверенность**; списки минимума и автопринятия общие, добавлен уровень 0,90.
- Сохранение шаблона `{{роль}}`, в том числе из цветных выделений, работает как в 1.6.3.

## Удалено

- Кнопки «Анонимизировать для LLM» и «Анализ LLM (запасной)»
- `LlmPlaceholderService`, `FieldAnonymizer`, `DocxToTaggedTextConverter`, `AnonymizedDocxBuilder`
- `config/llm-settings.json`, `AppPaths.LlmSettingsPath`, флаг `llm_fallback_enabled`

## Совместимость

Настройки пользователя (`user/settings/`) на удалённые кнопки не ссылались — миграция не требуется. Ключ `llm_fallback_enabled` в старом `config/contract-ner.json` при чтении игнорируется и при следующем сохранении настроек NER не записывается.

## Проверка

1. Настройки → Общие: версия программы **1.6.4**, версия модуля NER (например 1.1.1).
2. Вкладка «Шаблоны»: есть «Найти сведения» и «Сохранить шаблон»; кнопок LLM нет.
3. «Найти сведения» заполняет таблицу ролей, «Сохранить шаблон» пишет `{{роль}}`.
4. Цветные выделения по-прежнему сохраняются в шаблон без сети.
5. В «Настройках», на «Шаблонах» и на «Анонимизации» в списке уверенности есть **0,90**.
