## Назначение

Экспериментальная сборка: улучшения **пайплайна Contract NER** (стороны и границы) **без** переобучения модели.  
Откат: `release/Lassistant_v1.5.4.2_win-x64.zip` + `release/Lassistant_v1.5.4.2_src.zip`.

## Изменения NER

1. **Преамбула:** абзацы с обеими сторонами режутся по якорю `с одной стороны, и …` на два NER-чанка с разными `party_hint` (исполнитель / заказчик). Номер договора, предмет, цена не затрагиваются.
2. **Таблица реквизитов:** маркеры `ИСПОЛНИТЕЛЬ:` / `ЗАКАЗЧИК:` (с двоеточием) распознаются; sticky стороны из body не протекает в ячейки.
3. **Границы:** `expand_address` / `expand_textual` не выходят за конец NER-чанка (ячейка / кусок преамбулы). Sentence-NER не включался.

Модель / `labels.json` не менялись.

## Состав

Как у 1.5.4.2: `Lassistant.exe`, `config/`, `templates/`, `models/contract-ner/`, `scripts/contract_ner/`, `docs/`.

Архив: `release/Lassistant_v1.5.4.3_win-x64.zip`.
