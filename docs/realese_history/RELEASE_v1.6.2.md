# Lassistant 1.6.2

Дата: 2026-08-27  
Базовая линия: **1.6.1**  
Модуль NER: **1.1.1** (без смены весов)

## Summary

- Личные данные рядом с exe в `user/` — не затираются `publish.bat`.
- Форма «Создать документ» показывает поля выбранной карточки исполнителя.
- Окно «Настройки»: версии ПО и NER, формулировки вкладки NER, конструктор полей исполнителя.
- Документация в `docs/руководства/`: INSTALL_v1.6.2, руководство пользователя, словарь 76 ролей `{{ключ}}` — в md и HTML; файлы прошлых версий удалены.
- «О программе» — отдельное окно с кликабельными ссылками на документы (без кнопок «Да/Нет»).
- Publish копирует в `docs\` только `руководства\` и `правила\`.

## Проверка

1. Настройки → Общие: версия программы **1.6.2**, версия модуля NER (например 1.1.1).
2. Настройки → Пользователь → Добавить исполнителя: таблица стандартных пустых полей; добавить/удалить строку; сохранить.
3. «Создать документ»: набор полей исполнителя совпадает с карточкой (+ плейсхолдеры шаблона).
4. Повторный publish не стирает `user/`.
5. «О программе»: открываются руководство, словарь, инструкция по установке и папка с документацией из `docs\руководства`.
6. Словарь: только `{{…}}` из канона 76, без англ. ключей field-definitions.
