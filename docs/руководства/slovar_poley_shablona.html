Правила для юриста при правке шаблона
  • В Word вставляйте ключ целиком в фигурных скобках, например {{номер_договора}} — скопируйте из таблицы.
  • Не перепечатывайте ключ по буквам и не ставьте пробелы внутри: {{ номер_договора }} — неправильно.
  • Канон ролей: docs\правила\ROLE_SCHEMA_v1.1.1.md. Старые имена после постобработки NER приводятся к канону (таблица ниже).
  • Поля карточки исполнителя сверх этого списка тоже подставляются, если в DOCX есть такой {{ключ}}.
